# AI Sales Coach

An interactive discovery-call scenario. The learner hears a prospect objection, chooses a response, and gets tailored coaching feedback generated by Gemini.

Originally built in Articulate Storyline ([published version](http://robertelearning.s3.amazonaws.com/AI_Sales_Coach/story.html)); this is the standalone web version.

## Run it

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

## How it fits together

```
Browser (React)                  Cloudflare Worker                 Gemini
─────────────────                ──────────────────                ──────
scenario JSON  ──choice id──▶    builds coaching prompt  ──────▶  generates feedback
render + stream  ◀── { text } ── returns response        ◀──────
```

- **Content is data.** Everything a learner sees lives in [`src/scenarios/*.json`](src/scenarios/), separate from the code that runs it. Adding a scenario means adding a file, not rebuilding screens.
- **The API key stays server-side.** The browser only sends `{ "user_choice": "<choice id>" }` to the Worker; the Worker holds the Gemini key and the prompt.
- **Endpoint is configurable** with `VITE_COACH_ENDPOINT` (see `.env.example`).

## Project layout

| Path | What it is |
| --- | --- |
| `src/scenarios/` | Scenario content (setup, objection, choices) |
| `src/lib/coach.ts` | Client for the coaching Worker |
| `src/hooks/useWordStream.ts` | Word-by-word reveal (skipped for reduced-motion users) |
| `src/components/` | Intro, question, and feedback screens |

## Accessibility

- Streamed text is hidden from screen readers; the full line is announced once instead of word by word.
- Respects `prefers-reduced-motion` and `prefers-color-scheme`.
- Real buttons, a native `<dialog>`, and visible keyboard focus.
